# Site BRAGA SYSTEMS

Este é o código do site oficial. O contexto do projeto mora no repositório da marca, `Braga-ofc/BRAGASYSTEMS`: antes de escrever ou alterar qualquer arquivo daqui, leia tudo em `docs/contexto/` desse repositório (prd, architecture, rules, design, task e memory), a copy oficial em `site/COPY-OFICIAL-SITE.md` e o mapa técnico em `site/mapa-tecnico/`. Se ele não estiver na sessão, adicione-o antes de começar.

Trabalhe uma tarefa do `task.md` por vez, na ordem. Antes de cada tarefa, diga o que entra, o que sai e como testar; só avance depois do teste no link do Cloudflare. Toda decisão importante vai para o `memory.md` do repositório da marca, e a tarefa concluída é marcada lá.

Todo trabalho de interface usa a skill /impeccable e segue o `docs/referencias.md` do repositório da marca. Os textos vêm só da copy oficial: nada inventado. Nenhuma chave secreta entra no código, no GitHub ou no chat.

Até o lançamento, os commits vão direto para a `main` e aparecem no link de teste. Depois do lançamento, cada mudança vai numa branch, gera prévia e só vai para a `main` com o "pode publicar" do Gustavo. Commits em português, assinados como Braga-ofc.
